# 홈페이지 내부 가입 신청

## 변경 내용

- 독서클럽 가입 CTA는 `/join#application`으로 이동한다.
- `/join`의 기존 소개·참가비·FAQ를 유지하고 상단에 내부 신청서를 추가했다.
- 필수: 이름, 휴대전화, 개인정보 수집·이용 동의. 선택: 이메일, 주소 또는 거주 지역, 참여 목적.
- 브라우저 → `/api/join` → Apps Script → `가입신청` 탭으로 저장한다.
- HTTP 200 또는 전송 시작만으로 성공을 표시하지 않는다. `ok:true`, `saved:true`, 일치하는 `requestId`를 모두 확인한다.
- 환경변수가 없으면 접수 준비 상태를 표시하고 전송 버튼을 비활성화한다.
- 책쓰기스쿨의 별도 지원서와 기존 게시판·로그인 기능은 다른 신청 흐름이므로 유지한다.

## 기존 시트

Google Drive에서 확인한 기존 파일: `AI독서클럽_가입신청_DB`.

탭: `가입신청`. A~J 열은 기존 순서를 유지한다. 주소는 K열에 추가한다.

`접수번호 / 신청일시 / 이름 / 휴대전화 / 이메일 / 참여목적 / 개인정보동의 / 동의문버전 / 유입경로 / 처리상태 / 주소`

## Apps Script 설정

1. 해당 구글 시트 → 확장 프로그램 → Apps Script.
2. `google-apps-script/Code.gs` 내용을 붙여넣고 저장.
3. 프로젝트 설정 → 스크립트 속성에 `SPREADSHEET_ID`, `JOIN_FORM_SECRET` 추가.
4. 시트 ID는 저장할 구글 시트 URL의 `/d/`와 `/edit` 사이 문자열.
5. 비밀키는 비밀번호 관리자에서 만든 32자 이상 무작위 문자열을 사용. 계정 비밀번호를 사용하지 않는다.
6. 배포 → 새 배포 → 웹 앱. 실행 사용자 ‘나’, 액세스 ‘모든 사용자(로그인 없이 접근)’.
7. 본인 프로젝트의 시트 접근 권한을 승인하고 `/exec` 웹 앱 URL을 복사.

시트는 공개 공유하지 않는다. GET 요청은 설정 여부만 반환하며 신청자 정보를 반환하지 않는다.

## Vercel 설정

기존 `aibookclub` 프로젝트의 Production 환경:

| 이름 | 값 |
|---|---|
| `GOOGLE_SHEETS_WEB_APP_URL` | Apps Script 배포 `/exec` URL |
| `JOIN_FORM_SECRET` | Apps Script에 입력한 것과 동일한 비밀키 |

변경 후 새로 배포해야 한다. `NEXT_PUBLIC_` 접두어를 붙이지 않는다. 값은 Git, 로그 또는 채팅에 공개하지 않는다.

## 실제 연결 확인

1. 실URL 홈에서 ‘지금 가입하기’를 클릭해 같은 사이트의 신청서가 열리는지 확인.
2. 테스트 표시를 한 신청을 제출. 실제 사람의 불필요한 연락처는 사용하지 않는다.
3. 접수 완료 문구와 시트 새 행을 모두 확인.
4. 전화번호 앞자리 0, 주소 K열, 한국 시간, 동의 버전, 처리상태 ‘신규’ 확인.
5. 같은 접수번호 재전송은 1행으로 유지되는지 확인.
6. 동의 누락, 입력 오류, 구글 권한 실패, 응답 시간 초과는 성공으로 표시되지 않는지 확인.

`npm run check`는 로컬 검증이다. 실제 Google/Vercel 설정과 실URL 저장 검수는 별도이며, 로컬 통과만으로 연결 완료라고 표시하지 않는다.

## 개인정보 운영

신청 안내에 고지한 보유기간에 따라 가입 신청 처리 및 참여 안내가 끝난 기록을 파기한다. 가입 후 회원 관리 정보는 별도 안내에 따른다. 이번 기능은 마케팅 수신 동의를 수집하지 않으므로 홍보 메시지 수신 동의로 취급하지 않는다.
