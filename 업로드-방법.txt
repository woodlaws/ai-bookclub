■ GitHub 웹에서 업로드하는 방법
  1) github.com/woodlaws/ai-bookclub 접속
  2) 우측 상단 [Add file] → [Upload files]
  3) 이 폴더 안의 vendor 폴더와 8개 index.html 을
     폴더 구조 그대로 끌어다 놓기
     (index.html 은 최상위, 나머지는 각자 원래 폴더 안)
  4) 아래 커밋 메시지 입력 후 [Commit changes]

     Self-host React to remove external CDN dependency

  5) Vercel 이 자동 배포합니다 (1~2분)

■ 무엇이 달라지나
  전   unpkg.com(외국 서버)에서 React 를 받아야만 화면이 보임
       → 그 서버가 막히면 홈페이지가 완전 백지
  후   React 를 우리 저장소에 두고 먼저 읽음
       → 외부 서버 요청 0건, 백지 사고 불가능, 로딩도 빨라짐
